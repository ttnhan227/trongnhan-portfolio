# Workshop Village credits

## Artwork used by the playable village
- **Tiny Town — Kenney**, https://kenney.nl/assets/tiny-town — CC0. Buildings, terrain, trees and bushes. Original license: town/LICENSE.txt.
- **Tiny Dungeon — Kenney**, https://kenney.nl/assets/tiny-dungeon — CC0. Interior props and inventory objects. Original license: dungeon/LICENSE.txt.
- Both atlases are recolored at runtime to the village's shared 32-color palette; nearest-neighbor integer scaling preserves the 16×16 grid.
- Avatar, four-direction walk cycles, portraits, cat, flowers, mailbox, noticeboard, computer, water and particles: original procedural pixel artwork authored for this portfolio.
- Original 3×5 bitmap alphabet: authored for this portfolio.
- UI font: Silkscreen (SIL Open Font License); readable body font uses the existing site font stack.

## Audio
All area melodies, footsteps, dialogue blips, door sounds and discovery jingles are original Web Audio compositions authored for this portfolio. Muted by default; no third-party recordings are used by the game.
